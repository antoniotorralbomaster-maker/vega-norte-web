# vega-norte-web

Web estática de **AD Vega Norte** (club de fútbol base ficticio), caso de estudio del TFM «Vega Norte Digital» (Máster en IA Generativa, EBIS).

Esta primera versión contiene el contenido y la ficha de datos. Las instrucciones para construir la web con Claude Code están en [`CLAUDE.md`](CLAUDE.md).

## Contenido del repositorio
- `datos/club.json`: ficha de datos del club (ficticia).
- `datos/formularios.json`: especificación de los cuatro formularios.
- `contenido/paginas/`: texto de las páginas del MVP.
- `contenido/noticias/`: noticias de ejemplo.
- `diseno/tokens.css`: colores y tipografías del Manual de identidad v1.0.
- `CLAUDE.md`: brief para Claude Code.

Todos los datos, personas y empresas son ficticios.
